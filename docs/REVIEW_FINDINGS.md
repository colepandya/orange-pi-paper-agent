Each claim was checked against the current code (build 25), the legacy v4 app (retired 28 Oct 01:18 UTC) and reproduced with realistic SEC-style company names and press-release text.
The archive's `database.sql` was empty, so database counts could not be re-queried; everything below is from code and replay.

| # | Claim | Verdict | What was done |
