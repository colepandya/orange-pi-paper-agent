# Build 46: independent evaluation on real stored news

Generated from the final code. **There is no combined accuracy figure on purpose.**

## Method and limits

* Cases were SAMPLED by data characteristics from a 15,143-event export, then LABELLED from the headline alone by the build's author (one labeller, **not independent annotators**), before the engine was run on each set. Four sets: 233 cases used while finding defects, and a 53-case validation set drawn after the Build 45 rules were frozen.
* **The validation set is no longer fully independent**: while choosing Build 46's matcher rules the false matches of ALL sets, validation included, were read. Treat Build 46's gains below as partly fitted; the next real export is the real test.
* The universe used here is the 5,223-name file of the 31 October export. Your live universe is larger (7,169) and was built by this package's own generator; its false-match rate on real traffic is higher than measured here and cannot be reproduced without that file.
* 'Build 44' is the Build 44 classifier, analyst, matcher, evidence and red-team code under the same harness.
